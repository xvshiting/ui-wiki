布局 Layout

空间如何被组织，是视觉层级的基础。

Grid Layout

网格布局
Layout

通过列、行和间距建立稳定秩序，常见于仪表盘、卡片流、后台系统。

demo

Bento Grid

便当盒布局
Layout

不等面积模块形成强弱层级，适合产品主页、功能总览和品牌展示。

demo

Asymmetrical Layout

不对称布局
Composition

通过偏移、旋转和不等比例创造张力，常用于杂志化、创意型页面。

demo

Whitespace

留白
Spacing

不是“空”，而是用空间降低认知负担，让主要内容拥有呼吸感和高级感。

demo

视觉风格 Visual

材质、层次与颜色决定界面的“气质”。

Glassmorphism

玻璃拟态
Material

半透明 + 模糊背景 + 细边框，营造悬浮玻璃层的感觉。

demo

Neumorphism

新拟态 / Soft UI
Material

利用同色系内外阴影营造凸起或按压效果。点击按钮体验 pressed state。

click

Gradient Mesh

网状渐变
Color

多组径向渐变叠加形成柔和色彩场，常见于 AI、创意工具和品牌页。

demo

Elevation & Layering

层级与悬浮
Depth

通过阴影、透明度、尺寸和模糊建立前后关系，让重要元素“浮”起来。

hover

动画 Motion

让界面不仅“出现”，而是“有行为”。

Micro-interaction

微交互
Motion

用户操作后的短反馈，例如点赞、保存、复制成功。点击按钮观察反馈。

click

Spring Motion

弹性动画
Easing

模拟真实弹簧的超调和回弹，比线性运动更自然。点击圆球体验。

click

Morphing

形变动画
Transformation

元素在形状之间平滑过渡，常见于 loading、音乐视觉和品牌动态。

auto

Skeleton Loading

骨架屏
Loading

加载期间先呈现内容结构，降低等待感；Shimmer 动画强化“正在加载”的暗示。

loading

交互 Interaction

用户输入如何改变界面，决定产品的“手感”。

Hover Reveal

悬停揭示
Pointer

鼠标悬停后才暴露次级信息或操作，让默认界面保持干净。

hover

Magnetic Button

磁吸按钮
Pointer

按钮会轻微追随鼠标位置，制造有“吸力”的互动感。把鼠标在按钮附近移动。

move cursor

Accordion

手风琴折叠
Disclosure

把复杂信息分层收起，只在需要时展开，典型于 FAQ、设置页和帮助中心。

click
什么是渐进披露？ +
只展示当前必要的信息，把复杂度延后到用户真正需要的时候。
适合什么场景？ +
FAQ、复杂表单、筛选器、高级设置、信息密集型产品。

Progressive Disclosure

渐进披露
UX Pattern

先给用户最重要的信息，再按需要展开细节，减少一次性认知负担。

click
基础设置
高级参数、边界条件、专家选项等内容默认隐藏，仅在需要时出现。
